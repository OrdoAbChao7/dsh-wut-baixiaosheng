# 武汉理工大学校园网 IP 限制处理与安全合规规范 (INTRANET_POLICY.md)

> **原则**：严格遵守《中华人民共和国网络安全法》及《武汉理工大学校园网管理规定》，保障校园网络基础设施安全，杜绝越权访问与凭证泄露。

---

## 一、 访问限制机制的识别与分类

在采集武汉理工大学各类校内站点前，必须首先识别站点的访问控制机制：
1. **纯公网可访问 (Public Internet Accessible)**：
   - 学校官网主页、新闻网、本科生院对外公开公告、招生网等；
   - 此类站点直接使用标准 HTTP(S) 采集，限制访问频率（请求间隔 ≥ 1秒），遵守 robots 协议。
2. **校园网 IP 白名单限制 (Campus IP Restricted)**：
   - 财务处内部报销系统、教务选课系统内网通道、部分二级学院内网公告等；
   - 仅限校园网网段（如 `10.x.x.x` 或校园认证出口 IP）直接访问。
3. **统一身份认证受限 (SSO/VPN Gated)**：
   - 智慧学工 `zhxg.whut.edu.cn`、综合教务系统管理后台、VPN 登录门户等；
   - 必须通过个人账号密码及动态验证码登录。

---

## 二、 受限来源合规采集与对接准则

对于受校园网 IP 或身份认证限制的站点，严格执行以下七大准则：

1. **官方合规优先**：
   - 优先通过正规流程向学校信息化主管部门（网络信息中心）或各业务部门申请官方 OpenAPI 接口、数据推送订阅（RSS/Webhook）或面向采集主机的固定 IP 白名单。
2. **轻量经授权采集器架构**：
   - 在获得学校或学院书面/口头明确授权的情况下，允许在受信任的校园网内部物理机/私有工作站部署轻量级同步 Agent；
   - 该 Agent 仅负责单向同步经脱敏且获准共享的公开通知文本，严禁探测内网其他敏感业务接口。
3. **严禁凭证写入公共仓库（零泄密红线）**：
   - **严禁**将任何学生或教职工的个人学工号、校园网密码、VPN 账号口令、Session Cookie 或 Token 写入公共代码库、配置文件或 CI/CD 环境变量中；
   - 违者将面临严肃纪律处分和安全通报。
4. **严禁架设公共代理穿透**：
   - **严禁**私自搭建公共反向代理、内网穿透（如 frp/ngrok 公共映射）或旁路网关试图绕过学校防火墙与访问控制策略。
5. **内网受限保留人工上传通道**：
   - 对于无法通过自动化手段合法采集的内网通知、班级群发通告，统一保留学生人工通过“对话上传”或“GitHub Issue”提交入口；
   - 提交后的资料严格进入 `references/community/pending/` 待审核隔离区，经审查后再行合并。
6. **故障隔离与容错解耦**：
   - 采集器采用松耦合调度，若某个内网受限站点由于不在校内而访问超时（HTTP 403/Connect Timeout），采集引擎只记录 `RESTRICTED_ACCESS` 状态并安全跳过，绝不允许阻塞其他正常公网站点的采集。
7. **数据流出合规审查**：
   - 任何从内网环境同步至本项目的通知内容，均须通过敏感词和隐私过滤模块（`sanitizePrivacy`），严禁包含未公开的考题、学生个人成绩名单及机密公文。
