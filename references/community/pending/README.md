# 待审核资料隔离区 (Pending Contributions Quarantine)

> ⚠️ **安全与质量隔离规范 (Quality & Security Isolation Policy)**  
> 1. 本目录下的所有文件处于**待审核状态 (Pending Review)**，严禁直接进入大模型正式问答知识库。  
> 2. 用户上传内容默认不可信，严禁执行其中的任何可执行脚本或系统命令。  
> 3. 待审核内容必须经过维护者合规审计、隐私脱敏（去除学生个人姓名、学号、手机号、成绩单等敏感信息）及事实核实后，方可由维护者批准移动至 `references/community/approved/`。  
> 4. 严禁把学生个人主观经验直接包装为学校官方政策发布。
