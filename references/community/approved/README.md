# 已审核社区贡献知识库 (Approved Community Contributions)

本目录存放经维护者人工审核通过、已完成隐私脱敏且事实核查无误的学生社区贡献资料。

## 正式收录规范（必填元数据 Header）
每一份收录的正式文档均须包含以下元数据：
- **来源 (Source)**：如学院官网通知、年级辅导员群发文件、线下纸质通告等
- **发布时间 (Publish Date)**：原始文件的真实发布时间
- **适用范围 (Applicable Scope)**：适用的学院、专业、年级或校区
- **审核状态 (Verification Status)**：`APPROVED`（附审核人与审核日期）
- **原始文件 (Original File)**：归档的原件相对路径或哈希
- **最近更新时间 (Updated At)**：进入或更新知识库的时间戳
