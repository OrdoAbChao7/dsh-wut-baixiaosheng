# 武汉理工大学学分与绩点（GPA）计算及免修考核规定

> 来源公文：《武汉理工大学普通全日制本科学生学籍管理规定》（校教字〔2022〕44号）第十六条至第二十一条、第二十六条至第三十五条

---

## 一、平均学分绩点（GPA）计算公式

武汉理工大学本科课程考核成绩采用**5.0绩点分制**评定，平均学分绩点（Grade Point Average, GPA）计算公式为：

$$\text{GPA} = \frac{\sum (\text{课程绩点} \times \text{课程学分})}{\sum \text{课程学分}}$$

---

## 二、成绩与课程绩点折算标准

### 1. 百分制折算表（60分及以上折算为1.0~5.0）
| 考核成绩（百分制） | 对应绩点区间 | 课程绩点计算公式 |
|---|---|---|
| **90 ~ 100** | **4.0 ~ 5.0** | $\text{绩点} = 5.0 - (100 - \text{成绩}) \times 0.1$ |
| **80 ~ 89** | **3.0 ~ 3.9** | $\text{绩点} = 3.9 - (89 - \text{成绩}) \times 0.1$ |
| **70 ~ 79** | **2.0 ~ 2.9** | $\text{绩点} = 2.9 - (79 - \text{成绩}) \times 0.1$ |
| **60 ~ 69** | **1.0 ~ 1.9** | $\text{绩点} = 1.9 - (69 - \text{成绩}) \times 0.1$ |
| **< 60（不及格）** | **0** | $\text{绩点} = 0$ |

### 2. 等级制折算表
| 评定等级 | 对应分值 | 课程绩点 |
|---|---|---|
| **五级制·优秀** | 95 | **4.5** |
| **五级制·良好** | 85 | **3.5** |
| **五级制·中等** | 75 | **2.5** |
| **五级制·及格** | 65 | **1.5** |
| **五级制·不及格** | 0 | **0** |
| **两级制·合格** | 80 | **3.0** |
| **两级制·不合格** | 0 | **0** |

## 三、补考与重修机制

### 1. 补考规定
- **补考安排**：必修课程和专业选修课程首修考核不及格，学校在下学期开学初安排补考一次。
- **免补考课程**：通识选修课程、个性课程、独立设置的实验课程及集中实践教学环节不安排补考，直接给予一次免费重修机会。
- **补考成绩与绩点记载**：
  * 补考成绩合格者，成绩一律按 **60分（或及格/合格）** 记入成绩册；
  * 补考合格的课程绩点统一按 **1.0** 折算。
- **取消补考资格情形**：擅自旷考、考试违纪作弊、缺交平时作业或旷课超过1/3被取消考核资格者，不得参加补考，只能随后续年级重修。

### 2. 重修规定
- **必修课重修**：补考仍不及格的必修课程必须重修。
- **重修成绩与绩点记载**：重修成绩按实际成绩记入成绩册并注明“重修”，**课程绩点统一按 1.0 折算**。
- **刷分再次重修政策**：
  * 课程考核合格但成绩不理想者，在校期间**仅限重修一次**。
  * **在推荐免试研究生（保研）和评优评先时**：课程绩点严格取**第一次考核合格时的折算绩点**（如补考合格按1.0计）；
  * **在申请学士学位和对外出具中英文成绩单时**：课程绩点取**历次修读中的最高折算绩点**。

## 四、免听与免修考核规定

### 1. 申请前置资格
- 学生进校修读满一年；
- 已修读课程平均学分绩点（GPA）达到 **3.5 及以上**；
- 平均每学期取得学分达到 **25 学分及以上**。

### 2. 免听规定
- 每学期免听课程累计不得超过 **8学分** 或 **2门课程**；
- 须在开学前2周内向开课学院提交申请并报本科生院批准；
- 免听学生须按规定缴纳该门课程 **25%** 的学分学费；
- 必须按时完成作业、实验和实践环节，并参加期末统一考核。

### 3. 免修规定
- 须在开学前2周内提出免修申请，参加由开课学院组织的免修考核；
- 免修考核成绩达到 **70分及以上** 者准予免修，取得该课程学分；
- 免修课程成绩按实际免修考核成绩记入成绩册，并**免交该门课程的学分学费**；
- 考核低于70分者必须正常跟班上课。

### 4. 严禁免听、免修的课程门类
- 思想政治理论课；
- 军事理论课；
- 实验课及独立设置的实验环节；
- 体育课；
- 实习、课程设计、毕业论文（设计）等各类实践教学环节。
- **退役士兵特惠**：退役复学学生可申请免修体育、军训和军事理论课程，成绩统一按 **80分** 记入成绩册。

---

## 五、放弃课程政策

- 学生在满足毕业学分要求的前提下，毕业前可向学校申请放弃 **1 ~ 2 门** 选修课程或超出培养计划的课程；
- 经本科生院核准后，放弃的课程从学籍档案及对外成绩单中永久剔除，不计入GPA；
- **核心限制**：课程一旦放弃永久不予恢复；**必修课程绝对不得申请放弃**。
